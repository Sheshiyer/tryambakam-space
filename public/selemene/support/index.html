Support

Updated 8 October 2026.

Selemene is published and operated personally by Shesh Iyer. For private support, privacy questions, data requests, or a suspected security issue, email sheshnarayan.iyer@gmail.com. No response-time guarantee is offered.

Private support and data requests

Start with the action or tool you used, the approximate timestamp, any returned request or reading identifier, and the redacted error message. Do not include credentials, a full birth chart, or a complete private reading in the initial message.

For access or deletion requests, the publisher reviews what shared records can be identified and what action is feasible, then responds with the scope. The free connector has no linked personal account or personal history/deletion tool. Anonymous shared storage can make record matching incomplete; automatic erasure, a completion deadline, and full backup deletion are not guaranteed. See the privacy notice.

Public technical reports

For a reproducible engine or connector defect, use the Selemene issue tracker. GitHub issues are publicly visible. Use synthetic inputs and redacted screenshots.

Keep personal birth details, private readings, credentials, session cookies, and identifying logs out of public reports. Privacy, deletion, and suspected security issues belong in the private email channel.

Connection and availability

Do I need a Selemene key or account?

No. This free connector uses a sponsor credential kept on the server. It does not ask you to paste a key into chat or complete Selemene OAuth. The main website's browser-generated tn_free_… string is a demo, not a valid API credential, and is not needed here.

The service cannot authorize a request

A sponsor-service authorization failure needs operator attention; you cannot repair it with a personal key or by relinking a Selemene account. Send the sanitized error and timestamp to sheshnarayan.iyer@gmail.com. Do not send or request the sponsor credential.

An engine is missing or unavailable

Ask the connector which engines and workflows it currently exposes. A catalog entry alone does not prove the calculation backend is ready. The supported scope includes eleven reviewed non-media engines, the decision-support workflow, and a separate Vedic D1/D9 chart. It excludes administration, billing, media analysis, Suno, and full hosted witness reports.

I cannot find a public install link

The free calculation service is deployed and has been privately installed and tested. Public plugin-directory listing is still being prepared. These pages do not claim marketplace approval or provide an unverified installer.

Preparing and running a reading

A required input is missing

Provide the required field or choose a reading that does not need it. Do not guess an unknown birth time. Preparation does not execute a calculation. Before an ordinary reading is requested, review this disclosure:

Free readings use a shared Selemene administrator account. Birth inputs and calculated results may be stored there; usage, profile, XP and phase may change. There is no separate private user history.

A quota limit was reached

Limits apply to connecting IP addresses and the entire sponsored service. Shared networks or host gateways may share them. Respect the retry information actually returned; do not infer a personal balance or repeatedly retry. Defaults are described in the terms.

A calculation timed out or produced an ambiguous result

Treat its outcome as uncertain. Repeating it can create duplicate storage or usage effects. There is no personal history tool to check the record, and this connector does not silently re-execute ambiguous requests. Contact support with minimal identifiers if you need a review.

Can it create a narrated report, PDF, photo, or audio reading?

ChatGPT writes the explanation and final prose using your host limits. The free connector performs calculations and local symbolic draws; it does not run another hosted narration model or analyze photos/audio. Document exports depend on host-native tools that are actually available; a PDF or media generator is not included in these eight connector tools.

Understanding source limits

I Ching primary judgments and Great Symbolism images have original Legge-edition provenance, but moving-line passages are not supplied. Gene Keys activation values preserve their Human Design gate, line, and source; complete verified meanings remain incomplete or unverified. The Vedic chart supplies D1/D9 fields, not advanced yogas, dignities, combustion findings, Atmakaraka, or Darakaraka. See the reading guide before treating an absent field as a finding.
