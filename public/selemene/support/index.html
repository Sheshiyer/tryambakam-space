Selemene Engine · Support

Support — review draft

How to raise a technical issue, what to keep out of a public thread, and how to reason about the most common connection questions. This page describes intent while the ChatGPT integration is in preparation; it is not the final support surface.

Where to file a technical issue

Public issue tracker

For reproducible technical problems in the Selemene engine, the public issue tracker is:

github.com/Sheshiyer/Selemene-engine/issues

Issues on GitHub are publicly visible. Please do not include:

  • Personal birth information (date, exact time, place, coordinates).
  • Full reading outputs or personal interpretive content.
  • Passwords, API keys, OAuth tokens, or session cookies.
  • Private logs that identify you or other users.

Start with the action you attempted, the error message and timestamp, using synthetic data and redacted screenshots. Maintainers may request additional non-sensitive details.

Account, privacy, deletion

Account & data requests

A dedicated support channel for account, privacy, and deletion requests is pending publisher decisions. That private channel and the request-handling process must be established before this support page is ready for publication.

Until that channel is announced, please do not post account‑level or deletion requests to the public issue tracker. Wait for the published channel rather than share personal detail in public.

Troubleshooting

Common connection questions

Which credential connects my account?

The planned connection uses your own existing Selemene API key, entered in the secure browser authorization form. Never paste it into chat or a public issue. A shared operator key and the website’s tn_free_ demo string cannot substitute for your account credential. This draft does not offer a self-service account or key-creation flow.

Backend authorization vs. engine availability

Two distinct things can look like the same error:

  • Backend authorization — your connected credentials or permissions were not accepted. Re‑link from the secure browser form; do not paste tokens into chat.
  • Engine availability — the specific engine you asked for is not currently exposed by Selemene. Ask Selemene which engines it currently exposes. A catalog entry alone does not guarantee the calculation service is operational.

Ambiguous calculation timeouts

If a calculate or run_workflow call appears to hang or returns an ambiguous result, do not click retry repeatedly. Selemene does not automatically re‑execute an ambiguous run, and repeated retries can create duplicate history entries. Treat the outcome as uncertain and check available account history before deciding whether to request another reading.

The tn_free_… demo key

The website terminal on the main Tryambakam page may present a browser‑generated string beginning with tn_free_. That string is a demo: it is not a valid credential for Selemene and cannot authorize access to the ChatGPT integration. If you encountered a workflow asking you to paste it as an API key, that is out of scope for this draft.
